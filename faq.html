问答

先把边界说清楚。

这个网站现在能上课吗？

不能。所有课程都标成示例课程，章节里的文字是版式占位。

体验学生视图会打开隐藏内容吗？

不会。它只在当前浏览器标签多显示一行提示。刷新后如果还在，是因为这个标签自己记住了界面状态，没有上传。

为什么短视频和网盘打不开？

因为链接尚未配置，按钮也没有地址。以后只在 assets/js/links.js 填写 http 或 https。网盘能否访问由网盘服务商决定，本站演示不能授权。

页面会收集密码或邮箱吗？

不会。演示里的邮箱框是停用的，没有密码栏，也没有验证码。

目录为什么不能把所有课排成一列？

音乐、运动健身、旅游、烹饪是不同领域。筛选会先收窄领域，再收窄子技能，结果仍留在原来的分组里。

发布到 GitHub Pages 之后，登录会变成真的吗？

不会。这仍是静态文件。真账号、报名和私密笔记需要另做后端，不在这个原型里。
