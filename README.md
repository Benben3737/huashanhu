# 化山湖

公开示例静态网站。音乐、运动健身、旅游和烹饪按领域、子技能、课程、章节分开浏览。课程、笔记和作品介绍都是公开占位示例。

页面使用相对路径引用同目录里的 `assets/` 和 `favicon.svg`，不加载外部字体或 CDN。短视频和网盘地址留空时，页面显示「链接尚未配置」。右上角「体验学生视图」只改变当前标签页的提示，不收集邮箱或密码，也没有真实登录。

GitHub Pages 项目站点从 `main` 分支的根目录发布，公开地址是：

https://benben3737.github.io/huashanhu/

本仓库只有这些可公开的示例页面，不包含私人课件、学生资料或凭据。
