# 化山湖

人人可以分享技能、也可以学习别人分享的静态社区预览。音乐、运动健身、旅游、烹饪和其他领域都能整理。页面使用相对路径，不加载外部字体或 CDN。

现在能在浏览器里做的事：查看示例内容，用文字型、经验型、技术型三种模板在本机写草稿，写默认私有的学习笔记，只把勾选同意的课程感受放进本机评价预览，以及把当前选中的一份内容用浏览器打印或另存为 PDF。

还没有接通的事：邀请邮件、真实登录、跨用户发布、积分发放、兑换和线下预约。规则和接口见 [backend.html](backend.html)。新用户初始积分的数值尚未确定，页面不替任何人填写。
